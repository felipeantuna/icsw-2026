# WMS y TMS para e-Commerce

Repositorio inicial del Trabajo Práctico Integrador de Ingeniería y Calidad de Software.

El proyecto toma como contexto una plataforma de Gestión de Depósitos (WMS) y Gestión de Envíos (TMS) para una empresa de e-commerce.
